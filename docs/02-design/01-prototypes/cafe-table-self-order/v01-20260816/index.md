ขอบเขตของ prototype ชุดนี้: เฉพาะฝั่ง **ลูกค้า** (persona ลูกค้าใน user journey, ขั้นตอน C3–C6 เป็นหลัก) ไม่รวมหน้าจอฝั่งพนักงาน (persona พนักงาน S0–S5)

## หน้าจอ: หน้าเมนู (Menu Screen)

**Journey step ที่เกี่ยวข้อง:** C3 (เปิดหน้าเว็บเมนู เห็นรายการพร้อมราคา) · **ฟีเจอร์ที่เกี่ยวข้อง:** #1 (สแกน QR code เพื่อเปิดหน้าเว็บ), #2 (แสดงเมนูพร้อมราคา), #4 (ระบุหมายเลขโต๊ะอัตโนมัติ — แสดงผลในหน้านี้)

```text
┌─────────────────────────────────────┐
│  ร้านกาแฟใบไม้เขียว        [โต๊ะ 5]  │  <- type.h2 + Status Badge (3.3)
├─────────────────────────────────────┤
│ (i) เราเก็บเวลาที่สั่งและ IP address │  <- Privacy Notice Banner (3.7)
│     เพื่อการดำเนินงาน/ความปลอดภัย [x]│     dismissible, ไม่มีปุ่มยอมรับ/ปฏิเสธ
├─────────────────────────────────────┤
│ [ เครื่องดื่ม ] [ ของทานเล่น-เบเกอรี่ ]│  <- Segmented control (3.6 style)
├─────────────────────────────────────┤
│ ┌───────────┐   ┌───────────┐        │
│ │  [รูปภาพ]  │   │  [รูปภาพ]  │        │  <- Menu Item Card (3.2)
│ │        (+)│   │        (+)│        │     ปุ่ม + วงกลมมุมขวาล่างของรูป
│ │ ลาเต้ร้อน  │   │ อเมริกาโน่ │        │
│ │ ฿55.00     │   │ ฿45.00    │        │
│ └───────────┘   └───────────┘        │
│ ┌───────────┐   ┌───────────┐        │
│ │  [รูปภาพ]  │   │  [รูปภาพ]  │        │
│ │        (+)│   │        (+)│        │
│ │ คาปูชิโน่  │   │ ชาเขียวเย็น│        │
│ │ ฿60.00     │   │ ฿50.00    │        │
│ └───────────┘   └───────────┘        │
│              (เลื่อนดูรายการเพิ่มเติม) │
├─────────────────────────────────────┤
│  3 รายการ · ฿160.00   [ดูตะกร้า →]   │  <- Floating cart summary bar (3.9)
└─────────────────────────────────────┘     sticky bottom, แสดงเมื่อมี ≥1 รายการ

Toast (auto-dismiss 3s เมื่อกด +):
┌─────────────────────────────────────┐
│  ✓ เพิ่ม ลาเต้ร้อน ลงตะกร้าแล้ว        │  <- Toast (3.8)
└─────────────────────────────────────┘
```

### องค์ประกอบ (Component Mapping)

| ตำแหน่งในหน้าจอ | Component/Token (จาก DESIGN.md) |
|---|---|
| ชื่อร้าน (header) | `type.h2` |
| Badge หมายเลขโต๊ะ | Status Badge / Tag (3.3), พื้นหลัง `color.primary.100`, text `color.primary.700` |
| แถบแจ้งการเก็บข้อมูล | Privacy Notice Banner (3.7), พื้นหลัง `color.neutral.50`, ไอคอน `color.info`, text `type.caption` สี `color.neutral.600` |
| แท็บหมวดหมู่เมนู | Preset Selector / Segmented control style (3.6) |
| การ์ดเมนูแต่ละใบ | Menu Item Card (3.2), `radius.lg`, `shadow.sm` |
| ชื่อเมนูในการ์ด | `type.body-lg` |
| ราคาในการ์ด | `type.numeric` |
| ปุ่ม "+" เพิ่มลงตะกร้า | Buttons Primary (3.1) แบบวงกลมขนาดเล็ก, พื้นหลัง `color.primary.500` |
| แถบสรุปตะกร้าลอยด้านล่าง | Navigation floating cart summary bar (3.9), `shadow.md` |
| ปุ่ม "ดูตะกร้า" | Buttons Primary (3.1) |
| ข้อความแจ้งเพิ่มลงตะกร้าสำเร็จ | Toast / Inline Feedback (3.8), auto-dismiss 3 วินาที |
| ปุ่ม "ลองใหม่" (error state) | Buttons Secondary (3.1) |
| padding/gap ทั่วไประหว่างองค์ประกอบ | `space.4` |

### States

| State | คำอธิบาย |
|---|---|
| Loading | แสดง skeleton การ์ดเมนู (โครงสี่เหลี่ยมสีเทาซ้อนตำแหน่งรูป/ชื่อ/ราคา) ระหว่างโหลดเมนูครั้งแรก |
| Error | เชื่อมต่อไม่ได้ — แสดงข้อความเข้าใจง่าย เช่น "โหลดเมนูไม่สำเร็จ กรุณาลองใหม่" พร้อมปุ่ม Secondary "ลองใหม่" (ตาม UX guideline 4.5 กรณี wifi ร้านไม่เสถียร) |

## หน้าจอ: หน้าตะกร้า/สรุปรายการ (Cart Review Screen)

**Journey step ที่เกี่ยวข้อง:** C4 (เลือกรายการ ใส่จำนวน), C5 (ตรวจสอบรายการ แก้ไข หรือยืนยัน) · **ฟีเจอร์ที่เกี่ยวข้อง:** #3 (เลือกรายการ ใส่จำนวน และยืนยันคำสั่งซื้อ)

```text
┌─────────────────────────────────────┐
│  ← กลับ      ตะกร้าของคุณ            │  <- ปุ่ม back (ghost) + type.h2
├─────────────────────────────────────┤
│ ลาเต้ร้อน            ฿55.00          │
│         [ - ]  2  [ + ]     ฿110.00 │  <- quantity stepper + ราคารวม (type.numeric)
│                          [🗑 ลบ]     │
├─────────────────────────────────────┤
│ อเมริกาโน่            ฿45.00         │
│         [ - ]  1  [ + ]      ฿45.00 │
│                          [🗑 ลบ]     │
├─────────────────────────────────────┤
│                    ─────────────    │  <- divider
│              ยอดรวมทั้งหมด           │
│                        ฿155.00       │  <- type.numeric ตัวใหญ่
│                                       │
│                                       │
│   [      ยืนยันคำสั่งซื้อ      ]     │  <- ปุ่ม primary sticky bottom
│         (เต็มความกว้าง, สูง ≥44px)   │     วางครึ่งล่างของจอ (thumb zone)
└─────────────────────────────────────┘

Loading (ระหว่างส่งคำสั่งซื้อ):
   [   ⏳ กำลังส่งคำสั่งซื้อ...   ]      <- ปุ่ม disabled + spinner ในปุ่ม

Error (ส่งไม่สำเร็จ):
   ⚠ ส่งคำสั่งซื้อไม่สำเร็จ กรุณาลองใหม่   <- inline message สี color.error ใต้ปุ่ม
   [        ลองใหม่        ]

Empty state (ตะกร้าว่าง):
┌─────────────────────────────────────┐
│              🛒                      │
│      ยังไม่มีรายการในตะกร้า           │
│      [     กลับไปดูเมนู     ]        │  <- ปุ่ม primary
└─────────────────────────────────────┘
```

### องค์ประกอบ (Component Mapping)

| ตำแหน่งในหน้าจอ | Component/Token (จาก DESIGN.md) |
|---|---|
| ปุ่มกลับไปหน้าเมนู | Buttons Ghost/Text (3.1) |
| หัวข้อ "ตะกร้าของคุณ" | `type.h2` |
| Quantity stepper (ปุ่ม -/+) | อิงรูปแบบ Buttons (3.1) ขนาดเล็ก, touch target ≥44×44px (guideline 4.1) |
| ราคาต่อหน่วย/ราคารวมต่อรายการ | `type.numeric` |
| ปุ่มลบรายการ | Buttons Ghost/Text (3.1), ไอคอนถังขยะ |
| เส้นแบ่งก่อนสรุปยอด | divider สี `color.neutral.200` |
| ยอดรวมทั้งหมด | `type.numeric` ขนาดใหญ่ (อิง `type.h1`/`type.display` scale) |
| ปุ่ม "ยืนยันคำสั่งซื้อ" | Buttons Primary (3.1), พื้นหลัง `color.primary.500`, สูง ≥44px, sticky bottom |
| ข้อความ error ใต้ปุ่ม | Inline message (3.8), สี `color.error` |
| ปุ่ม "ลองใหม่" | Buttons Secondary (3.1) |
| Empty state: ปุ่ม "กลับไปดูเมนู" | Buttons Primary (3.1) |
| ระยะห่างระหว่างแถวรายการ/section | `space.3` / `space.4` |
| มุมโค้งของ card/stepper | `radius.md` |

### States

| State | คำอธิบาย |
|---|---|
| Empty | ตะกร้าว่าง — แสดงข้อความ "ยังไม่มีรายการในตะกร้า" พร้อมปุ่ม primary "กลับไปดูเมนู" (ตาม UX guideline 4.7) |
| Loading | ปุ่ม "ยืนยันคำสั่งซื้อ" แสดง spinner ในปุ่มและ disable ระหว่างส่งคำสั่งซื้อไปยังระบบ |
| Error | ส่งคำสั่งซื้อไม่สำเร็จ — แสดง inline message ใต้ปุ่มพร้อมปุ่ม "ลองใหม่" (ตาม UX guideline 4.5) |

## หน้าจอ: หน้ายืนยันคำสั่งซื้อสำเร็จ (Order Confirmed Screen)

**Journey step ที่เกี่ยวข้อง:** C6 (กดยืนยัน ระบบบันทึกหมายเลขโต๊ะอัตโนมัติ) · **ฟีเจอร์ที่เกี่ยวข้อง:** #3 (เลือกรายการ ใส่จำนวน และยืนยันคำสั่งซื้อ), #4 (ระบุหมายเลขโต๊ะอัตโนมัติ), #5 (แจ้งเตือนพนักงาน)

```text
┌─────────────────────────────────────┐
│                                       │
│              ✓                       │  <- checkmark icon สี color.success
│                                       │
│         ส่งคำสั่งซื้อสำเร็จ           │  <- type.h1
│                                       │
│         โต๊ะ 5 · 14:32 น.             │  <- หมายเลขโต๊ะ + timestamp
│                                       │
│           [ รอดำเนินการ ]             │  <- Status Badge (3.3) โทน warning อ่อน
│                                       │
├─────────────────────────────────────┤
│  รายการที่สั่ง                        │
│  ลาเต้ร้อน        × 2       ฿110.00  │  <- read-only list
│  อเมริกาโน่       × 1        ฿45.00  │
│  ─────────────────────────────       │
│  ยอดรวมทั้งหมด             ฿155.00   │  <- type.numeric
├─────────────────────────────────────┤
│  พนักงานได้รับแจ้งเตือนแล้ว            │  <- type.caption, color.neutral.600
│  กรุณารอรับที่โต๊ะ                     │
│                                       │
│       [   กลับไปหน้าเมนู   ]          │  <- ปุ่ม secondary
└─────────────────────────────────────┘
```

### องค์ประกอบ (Component Mapping)

| ตำแหน่งในหน้าจอ | Component/Token (จาก DESIGN.md) |
|---|---|
| ไอคอนความสำเร็จ (checkmark) | สี `color.success` |
| ข้อความ "ส่งคำสั่งซื้อสำเร็จ" | `type.h1` |
| หมายเลขโต๊ะ + เวลาที่สั่ง | `type.body`, `type.caption` (timestamp) |
| Badge "รอดำเนินการ" | Status Badge / Tag (3.3), โทนสี `color.warning` อ่อน |
| รายการที่สั่ง (read-only) | `type.body` (ชื่อ+จำนวน), `type.numeric` (ราคา) |
| ยอดรวมทั้งหมด | `type.numeric` |
| ข้อความแจ้งพนักงานรับทราบแล้ว | `type.caption`, สี `color.neutral.600` |
| ปุ่ม "กลับไปหน้าเมนู" | Buttons Secondary (3.1) |
| ระยะห่างระหว่าง section | `space.6` / `space.8` |

### States

หน้านี้แสดงเฉพาะหลังจากยืนยันคำสั่งซื้อสำเร็จแล้วเท่านั้น จึงไม่มี state loading/error เพิ่มเติมนอกเหนือจาก success state ด้านบน
