# Test Plan: ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)

> อ้างอิงจาก [[../../01-requirements/01-spec/20260802-01-cafe-table-self-order|ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)]], [[../../01-requirements/02-plan/20260815-01-cafe-table-self-order-feature-list|Feature List: ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)]] และ [[../../02-design/01-prototypes/20260815-01-cafe-table-self-order-user-journey|User Journey: ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)]]

## Acceptance Criteria

### ฟีเจอร์ #1: สแกน QR code เพื่อเปิดหน้าเว็บสั่งอาหาร

- **AC-cafe-table-self-order-01**: Given ลูกค้านั่งที่โต๊ะและได้รับ QR code เฉพาะของโต๊ะจากพนักงานแล้ว When ลูกค้าสแกน QR code ด้วยกล้องมือถือ Then ระบบเปิดหน้าเว็บสั่งอาหารสำเร็จโดยไม่ต้องติดตั้งแอพ และหน้าเว็บที่เปิดขึ้นตรงกับหมายเลขโต๊ะของ QR code นั้น

### ฟีเจอร์ #2: แสดงเมนูเครื่องดื่มและของทานเล่น/เบเกอรี่ พร้อมราคา

- **AC-cafe-table-self-order-02**: Given ลูกค้าเปิดหน้าเว็บสั่งอาหารแล้ว When หน้าเว็บโหลดเสร็จ Then ระบบแสดงรายการเมนูเครื่องดื่มและของทานเล่น/เบเกอรี่ทั้งหมดพร้อมราคาที่ถูกต้อง

### ฟีเจอร์ #3: เลือกรายการ ใส่จำนวน และยืนยันคำสั่งซื้อผ่านหน้าเว็บ

- **AC-cafe-table-self-order-03**: Given ลูกค้าอยู่ที่หน้าเมนู When ลูกค้าเลือกรายการ ใส่จำนวน และกดยืนยันคำสั่งซื้อ Then ระบบบันทึกคำสั่งซื้อพร้อมรายการและจำนวนที่ถูกต้อง (ระบบต้องป้องกันการยืนยันคำสั่งซื้อที่ว่างเปล่าหรือมีจำนวนไม่ถูกต้อง เช่น 0 หรือติดลบ)

### ฟีเจอร์ #4: ระบุหมายเลขโต๊ะอัตโนมัติจาก QR code

- **AC-cafe-table-self-order-04**: Given ลูกค้าสแกน QR code ของโต๊ะใดโต๊ะหนึ่งและยืนยันคำสั่งซื้อ When ระบบบันทึกคำสั่งซื้อ Then ระบบระบุหมายเลขโต๊ะที่ถูกต้องตรงกับ QR code ที่สแกนโดยอัตโนมัติ โดยไม่ต้องให้ลูกค้ากรอกเอง และไม่สลับกับโต๊ะอื่นแม้มีหลายโต๊ะสั่งพร้อมกัน

### ฟีเจอร์ #5: แจ้งเตือนพนักงาน/ครัวเมื่อมีออเดอร์ใหม่เข้ามา

- **AC-cafe-table-self-order-05**: Given ลูกค้ากดยืนยันคำสั่งซื้อสำเร็จ When ระบบบันทึกออเดอร์ใหม่ Then ระบบแจ้งเตือนพนักงาน/ครัวทันที พร้อมแสดงรายละเอียดออเดอร์และหมายเลขโต๊ะ ครบทุกออเดอร์แม้เข้ามาพร้อมกันหลายรายการ

### ฟีเจอร์ #6: พนักงานนำไปเสิร์ฟที่โต๊ะพร้อมเก็บเงินสดจากลูกค้า ณ โต๊ะ

- **AC-cafe-table-self-order-06**: Given พนักงานได้รับแจ้งเตือนออเดอร์ใหม่และจัดเตรียมสินค้าเสร็จแล้ว When พนักงานนำไปเสิร์ฟที่โต๊ะตามหมายเลขที่ระบบระบุ Then พนักงานเก็บเงินสดจากลูกค้า ณ โต๊ะได้ถูกต้องตามยอดคำสั่งซื้อ โดยไม่มีการชำระเงินผ่านระบบออนไลน์ในเวอร์ชันนี้

## ขอบเขตการทดสอบ (Test Scope)

**In scope:**

- สแกน QR code เฉพาะโต๊ะ → เปิดหน้าเว็บสั่งอาหารตรงกับหมายเลขโต๊ะ
- การแสดงเมนูเครื่องดื่ม/ของทานเล่น/เบเกอรี่พร้อมราคา
- การเลือกรายการ ใส่จำนวน แก้ไข และยืนยันคำสั่งซื้อ
- การระบุหมายเลขโต๊ะอัตโนมัติจาก QR code (รวมกรณีหลายโต๊ะสั่งพร้อมกัน)
- การแจ้งเตือนพนักงาน/ครัวเมื่อมีออเดอร์ใหม่
- การเก็บเงินสดที่โต๊ะตามยอดคำสั่งซื้อ

**Out of scope:**

- การชำระเงินออนไลน์ผ่านระบบ
- ระบบสมาชิก/สะสมแต้ม
- การรองรับหลายสาขา (multi-branch)
- แอพมือถือเฉพาะ (native app)
- ขั้นตอนพนักงานเดินนำ QR code ไปส่งให้ลูกค้าที่โต๊ะ (เป็นกระบวนการบริการของมนุษย์ ไม่ใช่ฟีเจอร์ซอฟต์แวร์ที่ทดสอบได้ — เป็น pain point ที่บันทึกไว้ใน user journey แต่ไม่มี test case ของระบบรองรับ)

## Test Data

| ชุดข้อมูล | รายละเอียด |
|---|---|
| QR code ของโต๊ะที่แตกต่างกัน | อย่างน้อย 2 โต๊ะ (เช่น โต๊ะ 1, โต๊ะ 2) สำหรับทดสอบว่าระบบระบุหมายเลขโต๊ะไม่สลับกัน |
| QR code ไม่ถูกต้อง | QR code ที่ไม่ถูกต้อง/เสียหาย/หมดอายุ สำหรับ negative test |
| รายการเมนูตัวอย่าง | อย่างน้อย 1 เครื่องดื่ม (เช่น กาแฟ) และ 1 ของทานเล่น/เบเกอรี่ พร้อมราคา |
| จำนวนสั่งซื้อ | ค่าปกติ (เช่น 2), ค่า 0, ค่าติดลบ, ค่ามาก (เช่น 99) สำหรับทดสอบขอบเขต |
| กรณีไม่เลือกรายการ | ไม่เลือกรายการใดเลยแล้วพยายามยืนยัน |
