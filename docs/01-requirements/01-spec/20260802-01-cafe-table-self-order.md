# ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)

> สร้างเมื่อ 2026-08-02

## บริบท / ที่มา

ร้านกาแฟต้องการให้ลูกค้าสั่งเครื่องดื่มและของทานเล่นได้เองจากโต๊ะ โดยไม่ต้องเดินไปสั่งที่เคาน์เตอร์ เพื่อลดคิวและเพิ่มความสะดวกให้ลูกค้า

## Feature Requirements

- หลังลูกค้านั่งที่โต๊ะ พนักงานนำ QR code เฉพาะของโต๊ะนั้นมาส่งให้ลูกค้า เพื่อให้ลูกค้าสแกนเปิดหน้าเว็บสั่งอาหาร (ไม่ต้องติดตั้งแอพ)
- หน้าเว็บแสดงเมนูเครื่องดื่ม (กาแฟ ฯลฯ) และของทานเล่น/เบเกอรี่ พร้อมราคา
- ลูกค้าเลือกรายการ ใส่จำนวน และยืนยันคำสั่งซื้อผ่านหน้าเว็บ
- ระบบระบุหมายเลขโต๊ะโดยอัตโนมัติจาก QR code (เพื่อให้พนักงานรู้ว่าออเดอร์มาจากโต๊ะไหน)
- ระบบแจ้งเตือนพนักงาน/ครัวเมื่อมีออเดอร์ใหม่เข้ามา
- พนักงานนำเครื่องดื่ม/อาหารไปเสิร์ฟที่โต๊ะ พร้อมเก็บเงินจากลูกค้า ณ โต๊ะ (ไม่มีการชำระเงินผ่านระบบออนไลน์ในเวอร์ชันนี้)

## User Stories / Use Cases

- ในฐานะลูกค้า ฉันต้องการรับ QR code จากพนักงานหลังจากนั่งที่โต๊ะแล้วสแกนเอง เพื่อดูเมนูและสั่งเครื่องดื่ม/ของทานเล่นได้เองโดยไม่ต้องรอพนักงานมารับออเดอร์อีกครั้ง
- ในฐานะพนักงาน ฉันต้องการเห็นออเดอร์ใหม่พร้อมหมายเลขโต๊ะทันทีที่ลูกค้ากดยืนยัน เพื่อจะได้จัดเตรียมและนำไปเสิร์ฟ พร้อมไปเก็บเงินที่โต๊ะ

## Business Rules

- ร้านมีสาขาเดียว (single-store) ไม่ต้องรองรับหลายสาขาในเวอร์ชันนี้
- การชำระเงินเกิดขึ้นที่โต๊ะหลังลูกค้าสั่ง (เก็บเงินปลายทางโดยพนักงาน) ไม่ใช่ online payment
- แต่ละโต๊ะต้องมี QR code เฉพาะของตัวเอง เพื่อระบุหมายเลขโต๊ะได้ถูกต้อง
- QR code ไม่ได้ติดเป็น sticker ถาวรที่โต๊ะ แต่พนักงานเป็นผู้ถือ/นำ QR code ของแต่ละโต๊ะไปส่งให้ลูกค้าด้วยตนเองหลังจากลูกค้านั่งลงที่โต๊ะแล้ว

## ขอบเขต (Scope)

- In scope: สั่งเครื่องดื่มและของทานเล่น/เบเกอรี่ผ่าน QR code ที่โต๊ะ, แจ้งเตือนพนักงานเมื่อมีออเดอร์ใหม่, การชำระเงินที่โต๊ะโดยพนักงาน
- Out of scope: การชำระเงินออนไลน์ผ่านระบบ, ระบบสมาชิก/สะสมแต้ม, การรองรับหลายสาขา, แอพมือถือเฉพาะ (native app)
