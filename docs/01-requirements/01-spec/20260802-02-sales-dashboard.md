# หน้า Dashboard ดูยอดขาย (Sales Dashboard)

> สร้างเมื่อ 2026-08-02

## บริบท / ที่มา

ร้านกาแฟมีระบบสั่งอาหารผ่าน QR code ที่โต๊ะอยู่แล้ว (ดู [[20260802-01-cafe-table-self-order|ระบบสั่งกาแฟจากโต๊ะ]]) ซึ่งทำให้มีข้อมูลออเดอร์เข้าระบบ เจ้าของร้าน/ผู้จัดการต้องการหน้าจอสรุปภาพรวมยอดขายจากข้อมูลออเดอร์เหล่านี้ เพื่อติดตามผลประกอบการของร้านโดยไม่ต้องนับยอดด้วยมือ

## Feature Requirements

- หน้า dashboard แสดงยอดขายรวม (ตัวเลขสรุป) ตามช่วงเวลาที่เลือก
- มีตัวเลือกช่วงเวลาแบบ preset ให้สลับดู: วันนี้, สัปดาห์นี้, เดือนนี้
- แสดงยอดขายแยกตามเมนู (เพื่อดูว่าเมนูไหนขายดี/ทำรายได้เท่าไหร่ในช่วงเวลาที่เลือก)
- แสดงกราฟแนวโน้มยอดขายรายวันในช่วงเวลาที่เลือก เพื่อดูแนวโน้ม/ช่วงเวลาที่ขายได้มาก
- ข้อมูลยอดขายทั้งหมดคำนวณจากออเดอร์ที่ลูกค้ายืนยันผ่านระบบสั่งอาหาร QR code (ไม่มีการป้อนข้อมูลยอดขายด้วยมือ)

## User Stories / Use Cases

- ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูยอดขายรวมของวันนี้/สัปดาห์นี้/เดือนนี้ เพื่อติดตามผลประกอบการร้าน
- ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูว่าเมนูไหนขายดีที่สุดในแต่ละช่วงเวลา เพื่อวางแผนสต็อกวัตถุดิบและโปรโมชั่น
- ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูกราฟแนวโน้มยอดขายรายวัน เพื่อดูว่าวันไหน/ช่วงไหนลูกค้าเข้าร้านมากเป็นพิเศษ

## Business Rules

- ยอดขายที่แสดงคำนวณจากยอดรวมของออเดอร์ที่ลูกค้ายืนยันผ่านระบบ QR code เท่านั้น (ระบบไม่มีการยืนยันการชำระเงินจริง เนื่องจากพนักงานเก็บเงินสดที่โต๊ะ ดังนั้นยอดขายในหน้านี้คือ "ยอดออเดอร์" ไม่ใช่ยอดเงินสดที่กระทบยอดแล้ว — ควรระบุข้อจำกัดนี้ไว้ในหน้าจอด้วย)
- ร้านมีสาขาเดียว (single-store) ไม่ต้องแยกยอดขายตามสาขา สอดคล้องกับ business rule ของระบบสั่งอาหารเดิม
- เวอร์ชันแรกยังไม่มีระบบ login/สิทธิ์การเข้าถึงเฉพาะผู้ใช้ — เปิดให้เข้าถึงหน้า dashboard ได้โดยไม่ต้องยืนยันตัวตน (ประเด็นการยืนยันตัวตน/สิทธิ์การเข้าถึงเป็นเรื่องที่ต้องพิจารณาเพิ่มเติมในอนาคต ควรถูกหยิบยกเป็นหัวข้อวางแผนต่อไป)

## ขอบเขต (Scope)

- In scope: หน้า dashboard แสดงยอดขายรวม, ยอดขายแยกตามเมนู, กราฟแนวโน้มยอดขายรายวัน, ตัวเลือกช่วงเวลาแบบ preset (วันนี้/สัปดาห์นี้/เดือนนี้)
- Out of scope (เวอร์ชันแรก): ระบบ login/สิทธิ์การเข้าถึงเฉพาะผู้ใช้, การเลือกช่วงเวลาแบบกำหนดเอง (custom date range), ยอดขายแยกตามโต๊ะ, การกระทบยอด (reconciliation) กับเงินสดจริงที่พนักงานเก็บได้, สิทธิ์การเข้าถึงสำหรับพนักงานทั่วไป (จำกัดกลุ่มผู้ใช้เป้าหมายไว้ที่เจ้าของร้าน/ผู้จัดการในเวอร์ชันนี้)
