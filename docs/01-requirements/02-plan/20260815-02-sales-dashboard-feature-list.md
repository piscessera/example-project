# Feature List: หน้า Dashboard ดูยอดขาย (Sales Dashboard)

> สร้างเมื่อ 2026-08-15
> อ้างอิงจาก [[../01-spec/20260802-02-sales-dashboard|หน้า Dashboard ดูยอดขาย (Sales Dashboard)]]

## รายการฟีเจอร์

| # | ฟีเจอร์ | คำอธิบาย | Priority | อ้างอิง User Story |
|---|---|---|---|---|
| 1 | ยอดขายรวม (ตัวเลขสรุป) ตามช่วงเวลาที่เลือก | หน้า dashboard แสดงตัวเลขยอดขายรวมของช่วงเวลาที่เลือกอยู่ | Must | ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูยอดขายรวมของวันนี้/สัปดาห์นี้/เดือนนี้ เพื่อติดตามผลประกอบการร้าน |
| 2 | ตัวเลือกช่วงเวลาแบบ preset (วันนี้/สัปดาห์นี้/เดือนนี้) | ผู้ใช้สลับดูข้อมูลได้ตามช่วงเวลาสำเร็จรูปที่กำหนดไว้ล่วงหน้า | Should | ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูยอดขายรวมของวันนี้/สัปดาห์นี้/เดือนนี้ เพื่อติดตามผลประกอบการร้าน |
| 3 | ยอดขายแยกตามเมนู | แสดงรายการยอดขายแบ่งตามเมนูในช่วงเวลาที่เลือก เพื่อดูว่าเมนูไหนขายดี | Should | ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูว่าเมนูไหนขายดีที่สุดในแต่ละช่วงเวลา เพื่อวางแผนสต็อกวัตถุดิบและโปรโมชั่น |
| 4 | กราฟแนวโน้มยอดขายรายวันในช่วงเวลาที่เลือก | แสดงกราฟแนวโน้มยอดขายรายวัน เพื่อดูว่าวันไหน/ช่วงไหนขายดีเป็นพิเศษ | Could | ในฐานะเจ้าของร้าน/ผู้จัดการ ฉันต้องการดูกราฟแนวโน้มยอดขายรายวัน เพื่อดูว่าวันไหน/ช่วงไหนลูกค้าเข้าร้านมากเป็นพิเศษ |

## หมายเหตุ

- ยอดขายที่แสดงในทุกฟีเจอร์ข้างต้นคำนวณจากออเดอร์ที่ลูกค้ายืนยันผ่านระบบ QR code เท่านั้น (ดู [[../01-spec/20260802-01-cafe-table-self-order|ระบบสั่งกาแฟจากโต๊ะ (QR code)]] ในฐานะแหล่งข้อมูลออเดอร์) ตัวเลขที่แสดงจึงเป็น "ยอดออเดอร์" ไม่ใช่ยอดเงินสดที่กระทบยอดแล้ว ทุกฟีเจอร์ที่แสดงยอดขาย (โดยเฉพาะ #1, #3, #4) ต้องระบุข้อจำกัดนี้ไว้บนหน้าจอให้ผู้ใช้เห็นชัดเจน ตาม business rule ของ spec ต้นทาง
- เวอร์ชันนี้ยังไม่มีระบบ login/สิทธิ์การเข้าถึง จึงไม่มีฟีเจอร์เกี่ยวกับการยืนยันตัวตนอยู่ในรายการนี้ (นอกขอบเขตตาม spec ต้นทาง แต่ถูกระบุว่าเป็นประเด็นที่ควรพิจารณาเพิ่มเติมในอนาคต)
- การเลือกช่วงเวลาแบบกำหนดเอง (custom date range), ยอดขายแยกตามโต๊ะ, และการกระทบยอด (reconciliation) กับเงินสดจริง อยู่นอกขอบเขต (out of scope) ตาม spec ต้นทาง จึงไม่ปรากฏในรายการนี้
