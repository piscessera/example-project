# Feature List: ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)

> สร้างเมื่อ 2026-08-15
> อ้างอิงจาก [[../01-spec/20260802-01-cafe-table-self-order|ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order System)]]

## รายการฟีเจอร์

| # | ฟีเจอร์ | คำอธิบาย | Priority | อ้างอิง User Story |
|---|---|---|---|---|
| 1 | สแกน QR code เพื่อเปิดหน้าเว็บสั่งอาหาร | ลูกค้าสแกน QR code ที่ติดอยู่บนโต๊ะเพื่อเปิดหน้าเว็บสั่งอาหารได้ทันที โดยไม่ต้องติดตั้งแอพ | Must | ในฐานะลูกค้า ฉันต้องการสแกน QR code ที่โต๊ะ เพื่อดูเมนูและสั่งเครื่องดื่ม/ของทานเล่นได้เองโดยไม่ต้องรอพนักงาน |
| 2 | แสดงเมนูเครื่องดื่มและของทานเล่น/เบเกอรี่ พร้อมราคา | หน้าเว็บแสดงรายการเมนูทั้งหมดพร้อมราคาให้ลูกค้าเลือก | Must | ในฐานะลูกค้า ฉันต้องการสแกน QR code ที่โต๊ะ เพื่อดูเมนูและสั่งเครื่องดื่ม/ของทานเล่นได้เองโดยไม่ต้องรอพนักงาน |
| 3 | เลือกรายการ ใส่จำนวน และยืนยันคำสั่งซื้อผ่านหน้าเว็บ | ลูกค้าเลือกสินค้า ระบุจำนวน และกดยืนยันคำสั่งซื้อได้เองผ่านหน้าเว็บ | Must | ในฐานะลูกค้า ฉันต้องการสแกน QR code ที่โต๊ะ เพื่อดูเมนูและสั่งเครื่องดื่ม/ของทานเล่นได้เองโดยไม่ต้องรอพนักงาน |
| 4 | ระบุหมายเลขโต๊ะอัตโนมัติจาก QR code | ระบบระบุหมายเลขโต๊ะโดยอัตโนมัติจาก QR code ที่ลูกค้าสแกน เพื่อให้พนักงานรู้ว่าออเดอร์มาจากโต๊ะไหน | Must | ในฐานะลูกค้า ฉันต้องการสแกน QR code ที่โต๊ะ เพื่อดูเมนูและสั่งเครื่องดื่ม/ของทานเล่นได้เองโดยไม่ต้องรอพนักงาน / ในฐานะพนักงาน ฉันต้องการเห็นออเดอร์ใหม่พร้อมหมายเลขโต๊ะทันทีที่ลูกค้ากดยืนยัน เพื่อจะได้จัดเตรียมและนำไปเสิร์ฟ พร้อมไปเก็บเงินที่โต๊ะ |
| 5 | แจ้งเตือนพนักงาน/ครัวเมื่อมีออเดอร์ใหม่เข้ามา | ระบบแจ้งเตือนพนักงาน/ครัวทันทีที่ลูกค้ากดยืนยันคำสั่งซื้อ | Must | ในฐานะพนักงาน ฉันต้องการเห็นออเดอร์ใหม่พร้อมหมายเลขโต๊ะทันทีที่ลูกค้ากดยืนยัน เพื่อจะได้จัดเตรียมและนำไปเสิร์ฟ พร้อมไปเก็บเงินที่โต๊ะ |
| 6 | พนักงานนำไปเสิร์ฟที่โต๊ะพร้อมเก็บเงินสดจากลูกค้า ณ โต๊ะ | พนักงานนำเครื่องดื่ม/อาหารไปเสิร์ฟที่โต๊ะตามหมายเลขที่ระบบระบุ พร้อมเก็บเงินสดจากลูกค้า ณ โต๊ะ (ไม่มีการชำระเงินออนไลน์ในเวอร์ชันนี้) | Must | ในฐานะพนักงาน ฉันต้องการเห็นออเดอร์ใหม่พร้อมหมายเลขโต๊ะทันทีที่ลูกค้ากดยืนยัน เพื่อจะได้จัดเตรียมและนำไปเสิร์ฟ พร้อมไปเก็บเงินที่โต๊ะ |

## หมายเหตุ

- ทุกฟีเจอร์ถูกจัดเป็น Must เนื่องจากเป็น MVP เดียวที่ระบุไว้ใน scope ของ spec ต้นทาง ไม่มีการแบ่งชั้นความสำคัญรอง (ไม่มีฟีเจอร์ระดับ Should/Could/Won't ในรอบนี้)
- ฟีเจอร์การชำระเงินออนไลน์, ระบบสมาชิก/สะสมแต้ม, การรองรับหลายสาขา และแอพมือถือเฉพาะ (native app) อยู่นอกขอบเขต (out of scope) ตาม spec ต้นทาง จึงไม่ปรากฏในรายการนี้
